# 📈 StockSense – Intelligent Stock Market Analytics Platform

StockSense is a web-based stock market analytics application designed to help users explore stock market trends, analyze historical price movements, track investments, and understand market performance through interactive visualizations.

Built using Python and Streamlit, StockSense brings multiple stock market tools together in one platform with a clean and user-friendly interface.

## 🌐 Live Application

**[Launch StockSense](https://stocksense-by-bhakti.streamlit.app/)**

## ✨ Key Features

### 1. 📊 Dashboard
- Market overview of NIFTY 50, SENSEX, and BANK NIFTY.
- Stock price tracking.
- Interactive candlestick charts.
- Market watch information.

### 2. 📈 Stock Analytics
- Simple Moving Average (SMA 20 and SMA 50).
- Relative Strength Index (RSI).
- Moving Average Convergence Divergence (MACD).
- Interactive stock charts and technical indicators.

### 3. 🤖 Stock Prediction
- Machine learning-based stock price estimation.
- Linear Regression model.
- Model evaluation using MAE, RMSE, and R².
- Actual vs. Predicted price visualization.

### 4. ⭐ Stock Watchlist
- Add preferred stocks.
- View current stock prices.
- Manage and remove stocks from the watchlist.

### 5. 💼 Portfolio Management
- Record stock purchases.
- Track investment amounts and current values.
- Monitor profit and loss.
- Visualize portfolio distribution through pie charts.

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/devbybhakti/StockSense.git
```

2. Navigate to the project folder:

```bash
cd StockSense
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

## 🎯 Project Objective

The objective of StockSense is to create an accessible and interactive platform that combines stock market analytics, technical indicators, machine learning-based price estimation, watchlist management, and portfolio tracking in one application.

The project aims to simplify stock market data analysis through interactive visualizations and an intuitive user interface.
